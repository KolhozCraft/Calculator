# Калькулятор в стиле Windows 11

Удобный калькулятор для компьютера. Выглядит как современный калькулятор Windows, умеет гораздо больше обычного и бесплатный.

## Что он умеет

**Обычный счёт.** Сложение, вычитание, умножение, деление, память (кнопки `MC`, `MR`, `M+`, `M-`, `MS`) и история: все ваши вычисления сохраняются, и любой результат можно использовать снова.

**Инженерный режим.** Синус, косинус, тангенс, логарифмы, степени, корни, факториал и число π. Углы можно считать в градусах или радианах.

**Графики.** Введите формулу, например `sin(x)`, нажмите Enter и увидите график.

**Конвертер.** Переводит одни единицы в другие. Доступно 13 категорий:

- Валюта
- Длина
- Вес и масса
- Объём
- Площадь
- Температура
- Скорость
- Время
- Энергия
- Мощность
- Данные (байты, мегабайты и так далее)
- Давление
- Угол

**Вычисление даты.** Сколько дней между двумя датами, какая дата будет через 30 дней, какая была 100 дней назад.

**Режим программиста.** Нужен не всем: работа с двоичной, восьмеричной и шестнадцатеричной системами счисления.

## Дополнительно

- Тёмная и светлая тема.
- Можно закрепить окно поверх всех остальных, чтобы калькулятор всегда был перед глазами.
- Размер окна можно менять.

> Курсы валют в конвертере записаны в программе заранее и сами не обновляются. Для точных расчётов проверяйте актуальный курс.

## Как установить и запустить

Понадобится компьютер с Windows и подключение к интернету. Установка занимает несколько минут.

### Шаг 1. Установите Python

Python нужен, чтобы программа запускалась.

1. Откройте [python.org/downloads](https://www.python.org/downloads/) и скачайте последнюю версию.
2. Запустите установщик.
3. **Важно:** внизу первого окна поставьте галочку **Add python.exe to PATH**, потом нажмите **Install Now**.

### Шаг 2. Скачайте калькулятор

1. Откройте страницу программы: [github.com/KolhozCraft/Calculator](https://github.com/KolhozCraft/Calculator).
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Распакуйте скачанный архив в любую папку, например на рабочий стол.

### Шаг 3. Установите нужные компоненты

1. Откройте папку с распакованной программой.
2. Нажмите на пустое место в строке адреса папки (сверху), напишите `cmd` и нажмите Enter. Откроется чёрное окно.
3. Вставьте туда команду и нажмите Enter:

```
pip install customtkinter matplotlib
```

Дождитесь окончания установки. Этот шаг делается один раз.

### Шаг 4. Запустите

Либо дважды щёлкните по файлу `windows_calculator.py`, либо в том же чёрном окне введите:

```
python windows_calculator.py
```

Калькулятор откроется.

## Частые вопросы

**Пишет, что `python` или `pip` не найден.**
Python установлен без галочки Add python.exe to PATH. Удалите его и установите заново, не забыв про галочку.

**Не открывается режим графиков.**
Не установился компонент matplotlib. Повторите команду из шага 3.

**Как выбрать другой режим?**
Нажмите на значок меню в левом верхнем углу окна, и откроется список режимов.

**Какие формулы можно вводить в графиках?**
Функции `sin`, `cos`, `tan`, `sqrt`, `log`, `ln`, `abs`, `pow`, числа `pi` и `e`, переменная `x`. Например: `sin(x)`, `x*x`, `sqrt(x)`.
